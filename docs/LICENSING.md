| Component | Licence |
|---|---|
| YSCE program and `runtime/` data | BSD 3-clause, Copyright 2022 Soji Yamakawa and the YSFlight Community Edition Development Committee (`!YSFlight.Licence`) |
| UnixLib (linked in) | UnixLib's licences (BSD-style and public domain parts) |

| PThreadTicker module | BSD (`!YSFlight.PThreadTicker-Licence`) |

The BSD licence's third clause means this port can't use the YSCE developers'
or Soji Yamakawa's names to promote it. The `YSCE-AircraftRefresh` models
have no licence file and are not included.
